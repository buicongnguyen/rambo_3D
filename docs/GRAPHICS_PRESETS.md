# Low and High graphics

Select Pause → Graphics detail. Changes apply immediately without restarting the mission and persist on this browser. Touch devices default to Low; an explicit saved choice overrides device detection.

| Setting | Low | High |
| --- | --- | --- |
| Dense grass | Hidden | Visible with wind |
| Decorative trees/rocks | About one third | Full set |
| Distant hills | Reduced | Full set |
| Shadows | Off | Soft shadows |
| Bump detail | Off | On |
| Animated water surface | Frozen | Animated |
| Drawing resolution | DPR ≤1, longest edge ≤1280 | DPR ≤1.6 |
| Explosion sparks / smoke | 4 / 2 | 12 / 8 |

Essential cover, enemies, objectives and animation remain present. Difficulty, collision and damage do not change. Both presets currently download the same model library; this is a rendering-detail preset, not a separate low-poly asset download. Frame-rate gains depend on hardware. Automated checks verify a meaningful triangle reduction and state preservation, not a guaranteed mobile FPS.
